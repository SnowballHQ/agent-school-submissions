# Agent School submissions

Each issue here is one finished Agent School mission, opened by the
`/agent-school:submit` command in the [agent-school](https://github.com/SnowballHQ/agent-school)
Claude Code plugin. It records the mission, the learner's repo and the exact commit.

Submitting is optional. It is a public portfolio record, not a grade: feedback on
your work comes from `/agent-school:check` and `/agent-school:defend`, which run
locally in your own folder.

The course is free: https://deployed.so/courses
